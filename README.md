# SauceDemo Manual Testing

Учебный проект по ручному тестированию веб-приложения SauceDemo.

## Цель проекта

Продемонстрировать навыки функционального тестирования интернет-магазина и оформления тестовой документации.

## Тестируемое приложение

https://www.saucedemo.com/

## Объём тестирования

Планируется проверить:

- авторизацию;
- каталог товаров;
- сортировку товаров;
- карточки товаров;
- корзину;
- оформление заказа;
- навигацию и выход из аккаунта;
- отображение ошибок и валидацию полей.

## Тестовая документация

В репозитории будут размещены:

- чек-лист;
- тест-кейсы;
- баг-репорты;
- итоговый отчёт о тестировании.
