# Чек-лист тестирования SauceDemo

## Авторизация

| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| AUTH-01 | Вход с корректными логином и паролем | Пользователь успешно авторизован и переходит в каталог товаров | Not run |
| AUTH-02 | Вход с корректным логином и неверным паролем | Авторизация не выполняется, отображается сообщение об ошибке | Not run |
| AUTH-03 | Вход с неверным логином и корректным паролем | Авторизация не выполняется, отображается сообщение об ошибке | Not run |
| AUTH-04 | Вход с неверными логином и паролем | Авторизация не выполняется, отображается сообщение об ошибке | Not run |
| AUTH-05 | Вход с пустыми полями | Авторизация не выполняется, отображается сообщение о незаполненном обязательном поле | Not run |
| AUTH-06 | Вход с пустым логином | Авторизация не выполняется, отображается сообщение об ошибке | Not run |
| AUTH-07 | Вход с пустым паролем | Авторизация не выполняется, отображается сообщение об ошибке | Not run |
| AUTH-08 | Ввод пробелов вместо логина и пароля | Авторизация не выполняется | Not run |
| AUTH-09 | Проверка чувствительности логина к регистру | Система обрабатывает введённые данные согласно правилам авторизации | Not run |
| AUTH-10 | Проверка чувствительности пароля к регистру | Пароль с изменённым регистром не принимается | Not run |
| AUTH-11 | Закрытие сообщения об ошибке | Сообщение об ошибке закрывается, форма остаётся доступной | Not run |
| AUTH-12 | Повторная успешная авторизация после ошибки | После исправления данных пользователь успешно входит в систему | Not run |
