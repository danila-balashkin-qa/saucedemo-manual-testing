# Чек-лист тестирования SauceDemo

## Авторизация

| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| AUTH-01 | Вход с корректными логином и паролем | Пользователь успешно авторизован и переходит в каталог товаров | Pass |
| AUTH-02 | Вход с корректным логином и неверным паролем | Авторизация не выполняется, отображается сообщение об ошибке | Pass |
| AUTH-03 | Вход с неверным логином и корректным паролем | Авторизация не выполняется, отображается сообщение об ошибке | Pass |
| AUTH-04 | Вход с неверными логином и паролем | Авторизация не выполняется, отображается сообщение об ошибке | Pass |
| AUTH-06 | Вход с пустым логином | Авторизация не выполняется, отображается сообщение об ошибке | Pass |
| AUTH-07 | Вход с пустым паролем | Авторизация не выполняется, отображается сообщение об ошибке | Pass |
| AUTH-08 | Ввод пробелов вместо логина и пароля | Авторизация не выполняется | Pass |
| AUTH-09 | Проверка чувствительности логина к регистру | Система обрабатывает введённые данные согласно правилам авторизации | Pass |
| AUTH-10 | Проверка чувствительности пароля к регистру | Пароль с изменённым регистром не принимается | Pass |
| AUTH-11 | Закрытие сообщения об ошибке | Сообщение об ошибке закрывается, форма остаётся доступной | Pass |
| AUTH-12 | Повторная успешная авторизация после ошибки | После исправления данных пользователь успешно входит в систему | Pass |
## Каталог товаров

| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| CAT-01 | Открытие каталога после успешной авторизации | Отображается страница Products со списком товаров | Pass |
| CAT-02 | Отображение информации в карточке товара | У товара отображаются название, изображение, описание, цена и кнопка добавления в корзину | Pass |
| CAT-03 | Переход в карточку товара по названию | Открывается страница выбранного товара с корректной информацией | Pass |
| CAT-04 | Переход в карточку товара по изображению | Открывается страница соответствующего товара | Pass |
| CAT-05 | Возврат из карточки товара в каталог | По кнопке Back to products открывается каталог | Pass |
| CAT-06 | Сортировка товаров по названию A–Z | Товары отображаются в алфавитном порядке | Pass |
| CAT-07 | Сортировка товаров по названию Z–A | Товары отображаются в обратном алфавитном порядке | Pass |
| CAT-08 | Сортировка товаров по цене от меньшей к большей | Товары отображаются по возрастанию цены | Pass |
| CAT-09 | Сортировка товаров по цене от большей к меньшей | Товары отображаются по убыванию цены | Pass |
| CAT-10 | Добавление товара в корзину из каталога | Кнопка меняется на Remove, возле корзины появляется счётчик | Pass |
## Корзина

| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| CART-01 | Открытие корзины после добавления товара | Открывается страница Your Cart, добавленный товар отображается в корзине | Not run |
| CART-02 | Отображение информации о товаре в корзине | Отображаются название, описание, цена и количество товара | Not run |
| CART-03 | Отображение количества товара | Для добавленного товара отображается количество 1 | Not run |
| CART-04 | Удаление товара из корзины | Товар удаляется, счётчик возле корзины уменьшается или исчезает | Not run |
| CART-05 | Возврат из корзины в каталог | По кнопке Continue Shopping открывается каталог товаров | Not run |
| CART-06 | Добавление двух разных товаров | В корзине отображаются оба товара, возле корзины указан счётчик 2 | Not run |
| CART-07 | Сохранение товаров при переходе между каталогом и корзиной | Добавленные товары остаются в корзине после переходов между страницами | Not run |
| CART-08 | Переход к оформлению заказа | По кнопке Checkout открывается первый шаг оформления заказа | Not run |
